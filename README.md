# 关山阅GEOMarkdown清理与排版

保守清理Markdown的BOM和换行，辅助检查标题与列表结构。适用于发布前排版，保护代码、链接和表格内容。

## 输入与输出

输入：UTF-8 Markdown文件及目标排版要求；若来源是HTML先用环境的转换工具提取并保留原件。

输出：cleaned.md、新旧差异与待人工检查项；保留原文件。

## 工作步骤

1. 使用 scripts/clean_markdown.py 写入新文件并输出变更摘要，拒绝覆盖输入。
2. 脚本只规范BOM和换行，保留所有文末空行，不自动改标题层级、代码、链接、HTML、数学公式或表格。
3. 再检查标题层级跳跃、列表歧义和渲染问题；需要修结构时给具体差异，代码区逐字保留。
4. 无法确定乱码原字符时保留并标出，不能猜字补事实。

## 使用方法

这是供支持 SKILL.md 的 AI 工具读取的工作流技能，不是独立网站或浏览器插件。

1. 从仓库 **Code → Download ZIP** 下载并解压，保留全部文件及目录结构。
2. 按所用 AI 工具的安装方式导入该目录；是否兼容以实际导入和运行结果为准。
3. 提供所需材料并明确调用 `seoguan-markdown-clean`。支持 `$技能名` 的宿主可使用下方示例。

依赖：Python 3.10 或以上，脚本仅使用标准库。需要宿主具备读取所提供材料的能力；宿主模型服务可能有费用。

本工具附带本地脚本，请先阅读[脚本用法与样例](references/script-usage.md)。
